# Sistema militar — documentación de trabajo

- `AUDITORIA.md`: inventario del código, conflictos con las decisiones, datos que faltan, preguntas y plan de migración de guardados.
- `MATRIZ.md`: estado de MIL-001 a MIL-171 frente al código, fase y archivo.
- `PLAN.md`: fases, contenido y dependencias.

Jerarquía de fuentes: 1) decisiones MIL-001 a MIL-171 del usuario (con sus sustituciones y la ratificación de MIL-075/MIL-081); 2) el código (realidad técnica, no autoridad para cambiar producto); 3) propuestas técnicas, sujetas a revisión si afectan a reglas.

Los resúmenes de las decisiones proceden del documento de entrega. No sustituyen al historial literal: las que no traen su texto figuran como «A cotejar».
